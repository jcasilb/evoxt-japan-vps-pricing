## “日本 IP”和“日本原生 IP”是两件事

这一项决定了你的 IP 能不能过某些平台的风控，也是宣传话术最容易含混的地方。已核验的例子很能说明问题：NoslaCloud 东京机房的 IPv4 经多个数据库判定是德国 IP 广播到日本使用，IPv6 才是日本原生；雨云明确标注 IP 非原生；也有商家在条款里直接写明香港和日本节点为广播 IP，不承诺能访问有特定要求的网站。

所以看到“日本原生 IP”先问一句：是 IPv4 原生还是 IPv6 原生。很多业务只走 IPv4，IPv6 原生对它没有意义。

## 几个真实会遇到的问题

**60ms 和 300ms 差别到底体现在哪？**
网页首字节时间、SSH 敲命令的回显、API 的往返次数，都会被这个差距放大。60-90ms 区间用起来接近国内跨省访问；300ms 以上，一次页面加载涉及几十个请求时，体感就是“卡”。

**CMI 线路电信用户能用吗？**
能。狗云东京标的是 CMI 线路，实测里电信走 163 骨干直连回来、联通走软银接联通骨干，所谓 CMI 主要是移动用户的红利，但三家都是直连不绕路，电信用户也不会吃太大亏。真正只对某一家友好的线路不多，看回程路由比看宣传词靠谱。

**东京和大阪都标 $2.99，选哪个？**
按用途选。东京属标准网络，流量额度更宽；大阪属官方 Premium Network 分组。但 Premium 只是分组名称，官方没公开逐条路由，别默认它一定优化了回国方向，开通后自己跑一次 traceroute 更实在。👉 [在结账页切换地区对比两边的可用套餐](https://bit.ly/EvoXt)

**月付还是预付？**
第一次买月付。Evoxt 虽然支持预付到 3 年，但在没验证过自己这条宽带表现之前，锁长时间没有意义。等你确认延迟和稳定性都能接受，再考虑年付或充余额让系统自动扣费。
